IIDX Toolbox (test build, 2026-10-16)

1. Copy iidx_toolbox.dll and iidx_toolbox.ini next to spice64.exe.
2. Add -k iidx_toolbox.dll to the spice2x command line (or in spicecfg: Options > DLL hooks).
3. In game press Insert to open the menu (change the key in iidx_toolbox.ini, [general] MenuKey).

The log is iidx_toolbox.log next to the DLL. Please send it after testing.
